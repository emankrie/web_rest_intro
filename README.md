# Intro to REST API Development via Express JS

This is a tiny project demonstrating the creation of
REST endpoints in order to explain them. This is not
production code at all but should help understand some of
the concepts of REST API. It solely allows students to
work along the class examples without any copy and
paste.

For some theory and tools to be used to test
the code in this repository, please see the
[REST](https://docs.find-santa.eu/programming/web/rest/)
section on [docs.find-santa.eu](https://docs.find-santa.eu/).
